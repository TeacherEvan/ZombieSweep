ZombieSweep — 3D Scene-Replacement Bridge (v2)

Design v2 · 2D GameScene canonical · Three.js replaces selected groups in-place · FEATURE_FLAGS.render3d gated

Key Design Decisions

  • • 2D GameScene stays canonical; 3D is a projection only
  • • Hidden sprites use setVisible(false); bodies stay active
  • • Orthographic Three camera matched to Phaser frustum
  • • UIScene split so HUD renders above 3D canvas
  • • FEATURE_FLAGS.render3d gates everything (zero regression)

Three Bridges (parallel)

  • • VehicleBridge — player vehicle only (NPCs are 2D chars)
  • • EnvironmentBridge — instanced houses + ground + fog/light
  • • EffectsBridge — projectiles, death bursts, combo pulse
  • • Each: mesh pool, enabled toggle, parity test
  • • No external GLTF in v1 (procedural geometry)

Risks & Success

  • • Risk: 3D occluding HUD → UIScene split (P0.6)
  • • Risk: projection drift → per-bridge parity test
  • • Risk: WebGL/CI → stub renderer + flag-off path
  • • Success: tests green on+off; no FPS regression >5%
  • • Success: HUD above 3D; input unaffected
